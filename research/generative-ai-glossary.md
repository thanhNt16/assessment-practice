# Generative AI Design — Glossary

Terms from [genai-design](16-genai-design.md). Sorted case-insensitively by term.

- Adversarial (patch) loss — patch-discriminator loss stacked onto tokenizer training to suppress high-res artifacts — [genai-design](16-genai-design.md)
- ANN — approximate nearest-neighbor search; exact NN is O(N x D) (40M comparisons/query at 40M chunks), so ANN is mandatory past millions of items; families: tree / LSH / clustering / graph — [genai-design](16-genai-design.md)
- ARES — framework for RAG evaluation alongside IR measures — [genai-design](16-genai-design.md)
- Autoregressive model — generates token-by-token, O(N²) but chunk-based (1024x1024 @ 64x64-pixel tokens = 256 steps); chosen for high-res synthesis at scale — [genai-design](16-genai-design.md)
- BatchNorm — normalization stabilizing activations in GAN generator blocks; permits higher learning rates in the adversarial two-network setup — [genai-design](16-genai-design.md)
- Beam search — decoding over the target sequence keeping top partial sequences; beats stochastic sampling on quality, determinism, coherence — [genai-design](16-genai-design.md)
- BLEU — classic n-gram sequence metric for translation quality — [genai-design](16-genai-design.md)
- BPE — byte-pair encoding; builds the subword vocabulary by iteratively merging the most frequent symbol pairs, so rare/unseen words decompose into known subwords — [genai-design](16-genai-design.md)
- Cascade super-resolution — inference-stage upscaling 64→256→1024 because diffusion models cannot generate high-res directly — [genai-design](16-genai-design.md)
- CIDEr — TF-IDF-weighted n-gram consensus against multiple human reference captions; captioning-specific metric — [genai-design](16-genai-design.md)
- Class-specific prior preservation loss — α x reconstruction(subject images) + β x prior(generic faces); keeps the model able to draw "a person", not just the user — [genai-design](16-genai-design.md)
- Classifier-free guidance — sampling fix giving prompt adherence in diffusion without a separate classifier — [genai-design](16-genai-design.md)
- CLIP similarity — embedding-similarity used for caption dedup, relevance-threshold filtering, and cross-modal alignment — [genai-design](16-genai-design.md)
- CLIPScore — cosine similarity of CLIP text/image embeddings; measures prompt-image alignment — [genai-design](16-genai-design.md)
- Codebook — discrete embedding table in VQ-VAE; nearest-embedding lookup quantizes the latent into one of k tokens the Transformer can predict — [genai-design](16-genai-design.md)
- Cross-attention — the load-bearing U-Net layer: queries from image features, keys/values from text embeddings, so the prompt steers denoising at every block — [genai-design](16-genai-design.md)
- Cross-entropy loss — per-position loss for next-token prediction in decoder-only training — [genai-design](16-genai-design.md)
- DDIM — sampling method cutting diffusion from 1000 steps to ~20 — [genai-design](16-genai-design.md)
- Diffusion model — iterative denoising (model predicts noise ε, loss = MSE); wins on image quality and sampling flexibility (step count = speed/quality dial), slow and costly — [genai-design](16-genai-design.md)
- DINO — visual-detail similarity metric; flags changes CLIP forgives (e.g. jacket color) — [genai-design](16-genai-design.md)
- DiT — diffusion Transformer alternative to U-Net: patchify → transformer → unpatchify — [genai-design](16-genai-design.md)
- DreamBooth — finetune-everything personalization; best identity preservation, gigabytes per subject, ~15 min finetune — [genai-design](16-genai-design.md)
- Encoder-only Transformer — with a prediction head, one option for language detection — [genai-design](16-genai-design.md)
- Failure to converge — GAN failure where discriminator accuracy → 50% and feedback becomes coin flips; fix with normalization or different learning rates — [genai-design](16-genai-design.md)
- FAISS — library shipping ANN indexes (with ScaNN, Elasticsearch) — [genai-design](16-genai-design.md)
- FID — image quality/diversity metric (with IS); per-frame use misses flicker — [genai-design](16-genai-design.md)
- FVD — Fréchet distance over I3D video features; captures temporal consistency that per-frame FID/IS miss — [genai-design](16-genai-design.md)
- GAN — generator + discriminator in competition; fast one-pass generation, structured latent space enables facial-attribute manipulation, unstable training — [genai-design](16-genai-design.md)
- HNSW — graph-family ANN index — [genai-design](16-genai-design.md)
- IS — Inception Score; image quality/diversity metric — [genai-design](16-genai-design.md)
- LAION Aesthetics Predictor — quality-scores images so below-threshold pairs are dropped — [genai-design](16-genai-design.md)
- Layout-Parser — AI-based document parsing: object detection → OCR → structured text/non-text blocks; rule-based parsers break on varied layouts — [genai-design](16-genai-design.md)
- LDM — latent diffusion model; VAE-based compression shrinks video 512x and diffusion runs entirely in latent space — [genai-design](16-genai-design.md)
- LoRA — freezes base weights W, learns low-rank ΔW = AB (r x (d_in + d_out) params); megabytes per subject — [genai-design](16-genai-design.md)
- LSH — locality-sensitive-hashing ANN family — [genai-design](16-genai-design.md)
- METEOR — classic sequence metric for translation — [genai-design](16-genai-design.md)
- Mode collapse — GAN failure producing one plausible image forever; fix with WGAN or unrolled GAN — [genai-design](16-genai-design.md)
- MoE — mixture of experts; efficiency lever for video-scale training alongside efficient attention — [genai-design](16-genai-design.md)
- Perceptual hashing — deduplicates caption/image pairs via perceptual hash — [genai-design](16-genai-design.md)
- Perceptual loss — VGG-feature loss stacked onto tokenizer training for high-res quality — [genai-design](16-genai-design.md)
- Posterior collapse — a too-powerful decoder ignores the latent, killing diversity (VAEs/GANs hit it at >=512x512); countered by discretizing (VQ) or constraining capacity — [genai-design](16-genai-design.md)
- RAFT — finetune the LLM with golden + distractor documents so it learns to ignore retrieval noise — [genai-design](16-genai-design.md)
- RAG — retrieval-augmented generation: parse → chunk → embed → ANN-index; balances cost, scalability, freshness where finetuning can't cite sources and full-context prompts overflow the window — [genai-design](16-genai-design.md)
- Ragas — framework for RAG evaluation alongside IR measures — [genai-design](16-genai-design.md)
- Rare-token identifier — placeholder like "[V]" or "SKS" avoiding tokens with prior meanings or fragmented random strings in personalization prompts — [genai-design](16-genai-design.md)
- RLHF — reward model learns score-consistent rankings, then reinforcement learning generates tokens maximizing that reward; 1-100 GPUs for days — [genai-design](16-genai-design.md)
- ROUGE — classic sequence metric alongside BLEU/METEOR — [genai-design](16-genai-design.md)
- ScaNN — library shipping ANN indexes — [genai-design](16-genai-design.md)
- Textual inversion — learns a new token embedding from 1 image; weakest point on the adaptation spectrum — [genai-design](16-genai-design.md)
- Top-p sampling — per-token nucleus sampling; seeds AR image generation from a random first token — [genai-design](16-genai-design.md)
- U-Net — downsampling + upsampling conv denoiser; cross-attention injects the prompt at every block — [genai-design](16-genai-design.md)
- VAE — encoder-decoder generative model; fast, stable training, low quality, limited control — [genai-design](16-genai-design.md)
- Vanishing gradients — GAN failure where the discriminator gets too good and the generator starves; fix with modified minimax loss or a WGAN critic — [genai-design](16-genai-design.md)
- ViT — vision Transformer encoder: patchify (256x256 → 64x64 patches) + learnable 1D positional encoding; chosen over CNN for long-range dependencies — [genai-design](16-genai-design.md)
- VQ-VAE — image tokenizer: CNN encoder → codebook quantizer → transposed-conv decoder; forces discrete latent use (no posterior collapse) and shrinks the learning space to k tokens — [genai-design](16-genai-design.md)
- WER — word error rate; classic sequence metric — [genai-design](16-genai-design.md)
- WGAN — critic-based GAN loss fixing vanishing gradients and mode collapse — [genai-design](16-genai-design.md)
