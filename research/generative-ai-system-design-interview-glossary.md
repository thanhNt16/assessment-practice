## Glossary — Generative AI System Design Interview

One line per term across the 11 chapter notes (16–26): definition as the note states it, tagged with its source note. Mechanical case-insensitive sort — no conceptual grouping.

`1D positional encoding` — sequence position only; may miss 2D spatial structure — [image-captioning](20-image-captioning.md)
`2D positional encoding` — row+col → vector; preserves spatial layout — [image-captioning](20-image-captioning.md)
`7-step framework` — clarify → frame as ML task → data → model → evaluate → system design → deploy/monitor; the answer skeleton for every GenAI design question — [genai-overview](16-genai-overview.md)
`Acceptance rate` — % of suggestions accepted; % of emails using the feature — [smart-compose](17-smart-compose.md)
`AdvBench` — adversarial robustness benchmark — [chatbot](19-chatbot-assistant.md)
`Adversarial loss` — −log D(x̂) with a discriminator; the patch-based variant per VQGAN reduces unnatural artifacts — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`AdvGLUE` — adversarial robustness benchmark — [chatbot](19-chatbot-assistant.md)
`AGIEval` — composite multitask benchmark — [chatbot](19-chatbot-assistant.md)
`Alignment (training stage)` — third LLM training stage on curated/expert-annotated data — [genai-overview](16-genai-overview.md)
`Alternating training` — freeze generator and train discriminator, then freeze discriminator and train generator; imbalance either way is empirically fatal — [face-generation](22-face-generation.md)
`ANN (approximate nearest neighbor)` — "close enough" neighbors at ~O(log(N)×D) vs exact O(N×D); needs preprocessing/extra storage — [rag](21-rag.md)
`Annoy` — tree-based ANN (space partitioning) — [rag](21-rag.md)
`Anonymize PII` — strip personal identifiers for privacy-law compliance — [chatbot](19-chatbot-assistant.md)
`Answer correctness` — RAG-triad axis: match to a reference answer (BLEU/ROUGE/METEOR) — [rag](21-rag.md)
`Answer relevance` — RAG-triad axis: completeness, no redundancy vs the query (LLM-as-judge) — [rag](21-rag.md)
`Augmentation` — flips, rotation, color adjustment; more variation, better generalization — [face-generation](22-face-generation.md)
`Autoregressive model` — image as a token sequence through a Transformer (DALL-E, Muse); detailed and controllable but token-by-token is too slow, no manipulable latent space — [face-generation](22-face-generation.md)
`Average completion time` — email writing speed with vs without the feature — [smart-compose](17-smart-compose.md)
`BART` — public encoder-decoder checkpoint to skip pretraining cost — [machine-translation](18-machine-translation.md)
`Base model` — post-pretraining model that continues text instead of answering it — [chatbot](19-chatbot-assistant.md)
`BatchNorm (BN)` — normalizes across the batch dimension per feature; wins in deep CNNs and GAN generators, also regularizes — [face-generation](22-face-generation.md)
`BBQ` — bias benchmark — [chatbot](19-chatbot-assistant.md)
`Beam search` — tracks top-k sequences (beam width k), prunes by cumulative probability, stops at EOS or max length; deterministic and coherent but similar outputs and long-sequence cost — [smart-compose](17-smart-compose.md)
`Bilingual vs multilingual finetuning` — one model per language pair (higher accuracy, N-pair ops cost) vs one model for many pairs (cheaper ops, cross-pair interference) — [machine-translation](18-machine-translation.md)
`BLEU` — precision of n-gram matches candidate→reference with a brevity penalty for short outputs; unfairly punishes correct-but-different wording — [machine-translation](18-machine-translation.md)
`BLIP-3` — auto-captioning model replacing missing/weak captions in data prep — [text-to-image](24-text-to-image.md)
`BOLD` — bias benchmark, 23,679 prompts over 5 domains — [chatbot](19-chatbot-assistant.md)
`BoolQ` — reading comprehension benchmark — [chatbot](19-chatbot-assistant.md)
`BPE (Byte-Pair Encoding)` — subword tokenization: start from characters + `</w>`, repeatedly merge the most frequent adjacent pair; compact vocab, unseen words decompose into known pieces — [machine-translation](18-machine-translation.md)
`C4` — general-text pretraining corpus (with Wikipedia, StackExchange) — [machine-translation](18-machine-translation.md)
`Causal masking` — decoder tokens may attend only to already-generated prefixes; unmasked self-attention breaks generation — [machine-translation](18-machine-translation.md)
`Chunk tokens` — 64×64 px per token; 256 sequential steps for 1024² instead of ~1M pixel steps — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`CIDEr` — captioning metric: caption + references → TF-IDF vectors → cosine similarity → averaged; consensus-based, weights rare words, blind to word-order semantics — [image-captioning](20-image-captioning.md)
`Class-specific prior preservation loss` — keeps generic class ability (any human face) during full-parameter finetuning; combined as overall loss = α × reconstruction + β × prior preservation — [headshot-personalization](25-headshot-personalization.md)
`Classifier-free guidance (CFG)` — sampling fix: amplify the conditioned mode, shrink the unconditioned one → images match prompts far better — [text-to-image](24-text-to-image.md)
`CLIP` — vision–language model scoring image–caption relevance (drop pairs below ~0.25) and dedup via embedding similarity — [image-captioning](20-image-captioning.md)
`CLIP score (image encoder)` — image-encoder cosine similarity between generated and reference image; the identity-alignment axis — [headshot-personalization](25-headshot-personalization.md)
`CLIP similarity` — per-frame CLIP image features vs text features, cosine similarity averaged/maxed — [text-to-video](26-text-to-video.md)
`CLIPScore` — text–image alignment metric: cosine similarity of CLIP text/image embeddings — [text-to-image](24-text-to-image.md)
`Codebook` — learnable table of k embeddings; each continuous vector is replaced by its nearest entry, producing integer token IDs — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Cold-start problem` — recommenders lack features for new items; captions supply textual features — [image-captioning](20-image-captioning.md)
`Common Crawl` — web corpus used for pretraining — [smart-compose](17-smart-compose.md)
`CommonsenseQA` — everyday-inference benchmark — [chatbot](19-chatbot-assistant.md)
`Compression network` — separately trained VAE (visual encoder → latents, visual decoder → pixels) that enables LDM — [text-to-video](26-text-to-video.md)
`Compute-optimal training` — DeepMind 2022: data should scale ~linearly with params; pairs token count to model size — [genai-overview](16-genai-overview.md)
`Conditional GAN (cGAN)` — condition-driven generation — [face-generation](22-face-generation.md)
`Context relevance` — RAG-triad axis: retrieval ranks all relevant docs top (hit rate, MRR, NDCG, Precision@k) — [rag](21-rag.md)
`Context window` — token budget for input + history; chatbot requirement ≥4096 tokens — [chatbot](19-chatbot-assistant.md)
`Cosine similarity` — embedding-similarity measure for retrieval (with Euclidean distance), CLIPScore, and CIDEr — [rag](21-rag.md)
`Cost per generation` — unit-economics metric beside time-per-image: model complexity, resolution, infrastructure — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`CoT (chain-of-thought)` — intermediate reasoning steps for multi-hop questions across documents; extends to test-time compute scaling — [rag](21-rag.md)
`Cross-attention` — lets the decoder focus on relevant source parts; in U-Net, queries from image features, keys/values from text-encoder embeddings — [machine-translation](18-machine-translation.md)
`Cross-entropy loss` — LLM training loss; masked positions only in pretraining, all positions in finetuning — [smart-compose](17-smart-compose.md)
`CrowS-Pairs` — bias benchmark, 9 categories — [chatbot](19-chatbot-assistant.md)
`Data flywheel` — user prompts, generated images, and feedback folded back into the training set — [text-to-image](24-text-to-image.md)
`DDIM` — cuts diffusion sampling steps from 1,000 to as few as 20 — [text-to-image](24-text-to-image.md)
`DDPM` — denoising diffusion probabilistic model; the diffusion training reference (predict ε, MSE loss) — [text-to-image](24-text-to-image.md)
`Decoder` — emits target tokens one at a time with masked (unidirectional) self-attention — [machine-translation](18-machine-translation.md)
`Decoder-only` — Transformer variant for generation, one token at a time (GPT, LLaMA, Gemini, Claude) — [smart-compose](17-smart-compose.md)
`Decoding service` — serves the tokenizer's decoder only; the encoder is training-only and never deployed — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Deduplication` — remove duplicate articles/images; prevents skewed learning and overexposure — [smart-compose](17-smart-compose.md)
`Deepfake` — identity-cloned generation risk; expected bonus topic with PII handling — [headshot-personalization](25-headshot-personalization.md)
`DeepSpeed` — parallelism fix for GPU OOM during training — [text-to-image](24-text-to-image.md)
`Deterministic sampling` — same input → same output (greedy, beam); consistency, predictable, low inappropriate-suggestion risk — [smart-compose](17-smart-compose.md)
`DINO / DINOv2 score` — self-supervised contrastive features capturing fine visual detail (yellow vs red jacket scores low DINO, high CLIP); use for image-to-image — [headshot-personalization](25-headshot-personalization.md)
`Discriminative model` — learns P(Y|X); classifies or predicts from input features (fraud detection, rating prediction) — [genai-overview](16-genai-overview.md)
`Discriminator` — binary classifier real vs generated; Conv2D stride-2 downsampling → sigmoid probability — [face-generation](22-face-generation.md)
`Distillation` — compresses the model to cut per-step latency (with quantization and parallel sampling) — [text-to-image](24-text-to-image.md)
`DiT` — ViT-style diffusion backbone: patchify → positional encoding → Transformer → unpatchify; the newer bet after U-Net — [text-to-image](24-text-to-image.md)
`DiT for video` — 3D patches, cross-attention on text conditioning; scales with data+compute; the Sora/Movie Gen choice over U-Net (SVD, Emu Video) — [text-to-video](26-text-to-video.md)
`Document chunking` — split docs before embedding; whole-doc vectors capture gist but miss details and bust token limits; length-based (chunk_size/overlap), regex, or structure-aware splitters; 5M pages ≈ 40M chunks — [rag](21-rag.md)
`Document parsing` — PDF → structured blocks; rule-based (fixed templates) vs AI-based (layout detection → OCR → structured blocks) — [rag](21-rag.md)
`DPO` — preference-optimization alternative to PPO for the RL stage — [chatbot](19-chatbot-assistant.md)
`DrawBench` — curated text-to-image prompt benchmark probing composition, interaction, context — [text-to-image](24-text-to-image.md)
`DreamBooth` — finetune all diffusion model parameters on the subject's images; max identity fidelity, GB storage per subject — [headshot-personalization](25-headshot-personalization.md)
`Dynamic retrieval` — decide when/what to retrieve (FLARE, Self-RAG) — [rag](21-rag.md)
`Elasticsearch` — full-text search: heavy scans, weak semantics — [rag](21-rag.md)
`Embedding` — dense low-dim vectors; fixes one-hot sparsity and missing semantics ("happy"/"joyful" close, "happy"/"sad" far) — [smart-compose](17-smart-compose.md)
`Encoder` — builds context vectors from the source via bidirectional self-attention — [machine-translation](18-machine-translation.md)
`Encoder-decoder` — Transformer variant where output transforms input (translation; T5, BART) — [smart-compose](17-smart-compose.md)
`Encoder-only` — Transformer variant for understanding: classification, NER, sentiment (BERT, RoBERTa) — [smart-compose](17-smart-compose.md)
`EOS` — end-of-sequence token terminating beam search — [smart-compose](17-smart-compose.md)
`ESRGAN` — CNN-based 2× super-resolution upscaler — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Exact nearest neighbor` — O(N×D) linear search; a correctness benchmark, never a production path at 40M scale — [rag](21-rag.md)
`ExactMatch@N` — % of generations matching the first N ground-truth words, averaged across lengths — [smart-compose](17-smart-compose.md)
`Failure to converge` — GAN failure: D accuracy falls toward 50% (coin-flip) → feedback becomes noise → quality collapses; fix: normalization, different learning rates, weight decay, noise into D inputs — [face-generation](22-face-generation.md)
`FAISS` — library shipping clustering-based ANN out of the box — [rag](21-rag.md)
`Faithfulness` — RAG-triad axis: answer grounded in retrieved context, no hallucination (human review, Ragas, ARES) — [rag](21-rag.md)
`FastText` — language-identification tool for filtering to target languages — [smart-compose](17-smart-compose.md)
`Feature store` — hand-crafted-feature infrastructure (Tecton, SageMaker) on the traditional-ML side — [genai-overview](16-genai-overview.md)
`Few-shot prompting` — input-output examples set format/tone — [rag](21-rag.md)
`FID (Fréchet Inception Distance)` — Inception v3 deep-layer features of generated vs real sets → mean + covariance each → Fréchet distance; lower = better — [face-generation](22-face-generation.md)
`Flash Attention` — named attention-efficiency work motivated by the O(n²) sequence cost — [smart-compose](17-smart-compose.md)
`FLOP count` — compute per forward pass; measures model cost alongside parameters (dense 4→3 layer = 21 FLOPs) — [genai-overview](16-genai-overview.md)
`Forward process` — adds Gaussian noise over t ∈ 1..1000 via a noise schedule; closed form jumps from x₀ straight to any x_t — [text-to-image](24-text-to-image.md)
`Functional requirements` — the what: business objective, features, languages; they shape the architecture — [genai-overview](16-genai-overview.md)
`FVD (Fréchet Video Distance)` — I3D features → Fréchet distance between generated vs real video distributions; lower = better; catches what frame metrics miss — [text-to-video](26-text-to-video.md)
`GAN` — generator vs discriminator trained adversarially; one forward pass (fast), structured latent space, unstable training — [face-generation](22-face-generation.md)
`Generator` — maps noise → image via stacked upsampling blocks (ConvTranspose2d + BatchNorm + ReLU, final Tanh) — [face-generation](22-face-generation.md)
`GQA` — inference-efficiency talking point (grouped-query attention) — [chatbot](19-chatbot-assistant.md)
`Gradient checkpointing` — save a subset of activations, recompute in backward; GPU-memory-bound fix — [genai-overview](16-genai-overview.md)
`Gradient penalty` — WGAN stabilization technique — [face-generation](22-face-generation.md)
`Greedy search` — always pick the argmax token; repetitive loops, misses high-probability paths — [smart-compose](17-smart-compose.md)
`Group Attention` — named attention-efficiency direction — [smart-compose](17-smart-compose.md)
`Group norm (GN)` — normalizes feature groups; very small batches where BN fails — [face-generation](22-face-generation.md)
`GSM8K` — math problem-solving benchmark — [chatbot](19-chatbot-assistant.md)
`H100` — GPU reference for compute math: 60 TFLOP/s ≈ 5.18 EFLOP/day — [genai-overview](16-genai-overview.md)
`Harm detection` — output-side gate blocking unsafe generated images/video — [text-to-image](24-text-to-image.md)
`HateCheck` — toxicity benchmark — [chatbot](19-chatbot-assistant.md)
`HellaSwag` — everyday-inference benchmark — [chatbot](19-chatbot-assistant.md)
`Hit rate` — retrieval metric: relevant doc retrieved in top-k — [rag](21-rag.md)
`HNSW` — graph-based ANN: hierarchical navigable small-world graph, coarse-to-fine descent — [rag](21-rag.md)
`Human evaluation` — pairwise picks between two outputs (more photorealistic / preferred); the most reliable judge of photorealism and nuanced helpfulness/safety — [face-generation](22-face-generation.md)
`HumanEval` — code benchmark — [chatbot](19-chatbot-assistant.md)
`HyperAttention` — near-linear efficient attention — [text-to-video](26-text-to-video.md)
`Image augmentation` — mirroring, slight rotations, scaling; essential when only 10–20 real images exist — [headshot-personalization](25-headshot-personalization.md)
`Image encoder` — compresses the image into embeddings; granularity trade-off: single global token vs per-patch token sequence — [image-captioning](20-image-captioning.md)
`Imagine Yourself` — Meta's tuning-free personalization: finetune base + visual encoder once — [headshot-personalization](25-headshot-personalization.md)
`Inception score (IS)` — exponentiated average KL divergence of Inception v3 class probabilities; peaked per-image (quality) + near-uniform marginal (diversity); higher = better — [face-generation](22-face-generation.md)
`Inference-time scaling` — more inference compute may improve outputs; budget test-time compute as a quality lever — [genai-overview](16-genai-overview.md)
`Instance norm (IN)` — normalizes each feature map per sample; style transfer, image generation — [face-generation](22-face-generation.md)
`k-d tree` — tree-based ANN via space partitioning — [rag](21-rag.md)
`KID` — kernel-based distance between generated and real distributions — [face-generation](22-face-generation.md)
`KV cache` — inference-efficiency talking point — [chatbot](19-chatbot-assistant.md)
`LAION Aesthetics Predictor` — quality model flagging blurry/over-/underexposed images — [image-captioning](20-image-captioning.md)
`LAION-400M` — public image dataset augmenting in-house images for tokenizer training — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Language detector` — encoder-only Transformer classifier routing by detected language; load-bearing, not an afterthought — [machine-translation](18-machine-translation.md)
`Latent diffusion (LDM)` — denoise compressed latent representations instead of pixels; factor-8 spatial+temporal compression → 512× smaller latents and 512× cheaper training — [text-to-video](26-text-to-video.md)
`Latent space` — learned space where each point maps to a distinct face; enables attribute control — [face-generation](22-face-generation.md)
`Layer norm (LN)` — normalizes the features of each sample; small/variable batches: RNNs, Transformers — [face-generation](22-face-generation.md)
`LLaVA / LLaMa3-Video` — video captioners for caption generation and re-captioning — [text-to-video](26-text-to-video.md)
`LLM` — decoder-only Transformer with billions of parameters — [chatbot](19-chatbot-assistant.md)
`LLM-as-judge` — compare Q&A with another model to judge answer relevance — [rag](21-rag.md)
`LMSYS Chatbot Arena` — leaderboard ranking models on 800K+ crowdsourced pairwise comparisons — [chatbot](19-chatbot-assistant.md)
`LoRA` — freeze W, learn low-rank delta ΔW = AB; trainable params drop from d_in×d_out to r×(d_in+d_out); megabyte adapters, small inference overhead — [headshot-personalization](25-headshot-personalization.md)
`LPIPS` — image/video frame-quality metric (ch1 Table 3; averaged over frames) — [genai-overview](16-genai-overview.md)
`LSH` — locality-sensitive hashing: similar points hash to the same bucket — [rag](21-rag.md)
`Margin ranking loss` — penalize when score(win) − score(lose) < margin m; the optimizer pushes the gap open — [chatbot](19-chatbot-assistant.md)
`MATH` — math problem-solving benchmark — [chatbot](19-chatbot-assistant.md)
`MBPP` — code benchmark — [chatbot](19-chatbot-assistant.md)
`METEOR` — harmonic mean of precision+recall; matches synonyms/stems via WordNet; best human-judgment correlation — [machine-translation](18-machine-translation.md)
`Minimax loss` — unified GAN objective: D maximizes, G minimizes — [face-generation](22-face-generation.md)
`Mixed precision (AMP)` — most math in 16-bit, sensitive ops in 32-bit; speed + memory without accuracy loss — [genai-overview](16-genai-overview.md)
`MMLU` — broad multitask benchmark — [chatbot](19-chatbot-assistant.md)
`MMMU` — composite multitask benchmark — [chatbot](19-chatbot-assistant.md)
`Mode collapse` — generator finds one plausible image that fools D and keeps emitting it → limited variety — [face-generation](22-face-generation.md)
`MoE` — sparse expert compute as a training cost lever — [text-to-video](26-text-to-video.md)
`Movie Gen Bench` — curated text-to-video benchmark — [text-to-video](26-text-to-video.md)
`MRR / nDCG / mAP / P@k` — ranking metrics vs ground truth — [genai-overview](16-genai-overview.md)
`MSE / MAE / RMSE` — regression metrics vs ground truth; MSE is also the diffusion and reconstruction loss — [genai-overview](16-genai-overview.md)
`mT5 / mBART` — multilingual encoder-decoder models often matching bilingual accuracy — [machine-translation](18-machine-translation.md)
`Multi-head attention` — self-attention in parallel subspaces — [genai-overview](16-genai-overview.md)
`Multi-token prediction` — follow-up talking point beyond next-token — [chatbot](19-chatbot-assistant.md)
`Multinomial sampling` — samples the full predicted distribution; flat distributions → incoherent text; rarely used — [chatbot](19-chatbot-assistant.md)
`Multiple reference captions` — several annotators per validation image; makes training robust to phrasing and evaluation fairer — [image-captioning](20-image-captioning.md)
`Named-entity placeholder` — replace entities with `ENTITY_1`-style tokens, restore after translation — [machine-translation](18-machine-translation.md)
`Natural Questions` — world-knowledge benchmark — [chatbot](19-chatbot-assistant.md)
`Next-token prediction` — predict the following token; the pretraining and finetuning objective — [smart-compose](17-smart-compose.md)
`Noise schedule (β_t)` — grows with t; early steps preserve the image, later ones accelerate destruction — [text-to-image](24-text-to-image.md)
`Non-functional requirements` — the how: latency, throughput, fairness, security, scalability; rarely change the initial architecture but drive later tuning — [genai-overview](16-genai-overview.md)
`Normalization layer` — keeps activation distributions consistent amid two competing networks; enables higher learning rates — [face-generation](22-face-generation.md)
`NSFW filter` — keyword filtering / cleaning-pipeline removal of inappropriate content — [smart-compose](17-smart-compose.md)
`OCR` — per-box text extraction in reading order — [rag](21-rag.md)
`One-hot encoding` — sparse ID representation; fixed by embeddings — [smart-compose](17-smart-compose.md)
`Online evaluation metrics` — business-aligned: CTR, conversion, latency, engagement, revenue/user, churn, retention — [genai-overview](16-genai-overview.md)
`OpenBookQA` — everyday-inference benchmark — [chatbot](19-chatbot-assistant.md)
`Patchify` — divide image into fixed-size patches → flatten → linearly project (256×256 with 64×64 patches → 16 tokens) — [image-captioning](20-image-captioning.md)
`Perceptual hashing` — dedup near-identical images — [image-captioning](20-image-captioning.md)
`Perceptual loss` — distance between pretrained-VGG layer-l feature maps of original vs reconstruction; preserves content/style features — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Perplexity` — exp of average negative log-likelihood; lower = better next-token prediction; only a baseline — [smart-compose](17-smart-compose.md)
`Personalization` — adapting a pretrained T2I model to learn a new subject so prompts actually depict them — [headshot-personalization](25-headshot-personalization.md)
`Pipeline parallelism` — layers split across devices (inter-layer); very deep models — [genai-overview](16-genai-overview.md)
`PIQA` — everyday-inference benchmark — [chatbot](19-chatbot-assistant.md)
`Positional encoding` — required because attention is permutation-invariant; fixed sine-cosine vs learned — [smart-compose](17-smart-compose.md)
`Post-processing service` — rule-based bias control: pronoun neutralization, gender-neutral words, flagged-term analysis, NSFW filtering — [smart-compose](17-smart-compose.md)
`Posterior collapse` — decoder grows powerful enough to model output without latents → low diversity; fix: discrete latents via a quantizer — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`PPL` — image-generation metric (ch1 Table 3) — [genai-overview](16-genai-overview.md)
`PPO` — RL loop: generate responses → reward model scores them → update toward high-scoring responses — [chatbot](19-chatbot-assistant.md)
`Precision / recall / F1 / accuracy` — classification metrics vs ground truth — [genai-overview](16-genai-overview.md)
`Precomputed latents` — cache latents for all videos (~200 TB); per-step VAE encoding stalls every training iteration — [text-to-video](26-text-to-video.md)
`Prediction head` — final layer producing a probability per vocabulary token — [smart-compose](17-smart-compose.md)
`Preference pairs` — (prompt, winning, losing) tuples from annotator rankings; rankings beat absolute scores — [chatbot](19-chatbot-assistant.md)
`Pretraining` — stage 1 on general data (Common Crawl); next-token prediction with cross-entropy — [smart-compose](17-smart-compose.md)
`PrivacyQA` — privacy/PII-leakage benchmark — [chatbot](19-chatbot-assistant.md)
`Progressive growing` — named extension: multi-scale architectures — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Prompt engineering` — cheap, instantly editable LLM customization; inconsistent with phrasing and can't scale past the context window — [rag](21-rag.md)
`Prompt enhancer` — expands acronyms, fixes typos, adds context before the LLM — [chatbot](19-chatbot-assistant.md)
`Prompt safety service` — input gate rejecting violating prompts before compute — [text-to-image](24-text-to-image.md)
`Prompt template` — combine subject/recipient/previous emails into one tagged sequence — [smart-compose](17-smart-compose.md)
`QuAC` — reading comprehension benchmark — [chatbot](19-chatbot-assistant.md)
`Quantization loss` — distance between encoder output and nearest codebook vector; stop-gradient blocks flow so the codebook isn't updated — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Quantizer` — embedding-table module replacing each continuous vector with its nearest codebook entry → integer token IDs — [high-res-synthesis](23-high-resolution-image-synthesis.md)
`Query expansion` — rewrite the query (fix typos, broaden scope) before embedding; improves retrieval too (Query2doc) — [rag](21-rag.md)
`R-tree` — tree-based ANN via space partitioning — [rag](21-rag.md)
`RAFT (Retrieval-Augmented Fine-Tuning)` — label retrieved docs golden vs distractor; loss penalizes distractor use; hardens generation against noisy retrieval — [rag](21-rag.md)
`RAG` — retrieval-augmented generation: retrieval + generation coupled; answer quality hostage to retrieval quality — [rag](21-rag.md)
`RAG triad` — context relevance + faithfulness + answer relevance (+ correctness); one aggregate score hides which component broke — [rag](21-rag.md)
`Random sampling` — draw latent vectors from a standard Gaussian over the full space → diverse outputs; the default for faces — [face-generation](22-face-generation.md)
`Rare-token identifier` — DreamBooth subject token `[V]` built from rare vocabulary tokens; distinct yet tokenizer-cohesive (common words carry meaning, random strings fragment) — [headshot-personalization](25-headshot-personalization.md)
`RCAN` — CNN-based 2× super-resolution upscaler — [high-res-synthesis](23-high-resolution-image-synthesis.md)
