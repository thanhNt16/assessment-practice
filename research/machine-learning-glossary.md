## Machine Learning System Design — Glossary

Terms from [ml-design](17-ml-design.md). Sorted case-insensitively by term.

- A3 defense — committee-form system-design interview: the panel probes how the ML objective was framed, the feature/data pipeline built, and metrics justified — [ml-design](17-ml-design.md)
- All-ones embeddings — degenerate solution where a loss over observed pairs only reaches zero with all-identical embeddings; fix by weighting unobserved pairs (WALS) — [ml-design](17-ml-design.md)
- ANN — approximate nearest-neighbor search; exact NN is O(N×D), infeasible at billions, so ANN (tree-based, LSH, clustering; Faiss/ScaNN) is mandatory past millions of items — [ml-design](17-ml-design.md)
- AP — average precision: averages precision over IOU thresholds because precision varies with the threshold — [ml-design](17-ml-design.md)
- Batch prediction — precompute and store all outputs offline (embeddings indexes, whole PYMK lists); accepts wasted compute on inactive users as a stated trade — [ml-design](17-ml-design.md)
- BERT — contextual Transformer text encoder; chosen over BoW/TF-IDF (no semantics) and word2vec (static vectors) for video-search text retrieval — [ml-design](17-ml-design.md)
- Candidate generation — first serving stage narrowing millions/billions of items to hundreds via ANN, inverted index, FoF, or rule-based filters before the heavy ranker — [ml-design](17-ml-design.md)
- Class-balanced loss — loss reweighting for extreme class imbalance (event attendance); alternative to focal loss — [ml-design](17-ml-design.md)
- Click-through rate (CTR) — probability a shown item is clicked; the ad-system core prediction (pCTR) that downstream bidding depends on — [ml-design](17-ml-design.md)
- Clickbait optimization — maximizing clicks or raw reactions rewards clickbait; fix with weighted negative signals and relevance-aware objectives — [ml-design](17-ml-design.md)
- CLIP — image encoder used for feed-post features alongside ResNet — [ml-design](17-ml-design.md)
- Cold start — no interaction data for new users/items; handled via demographic features and heuristics, then fine-tuning as data accumulates; ephemeral events have it intrinsically — [ml-design](17-ml-design.md)
- Collaborative filtering — recommends from interaction patterns alone; discovers well but suffers cold start — [ml-design](17-ml-design.md)
- Continual learning — continuously fine-tune → evaluate → deploy only on metric improvement; essential when a 5-minute update delay measurably hurts (ads) — [ml-design](17-ml-design.md)
- Contrastive training — trains encoders so similar pairs sit close in embedding space: dot-product/cosine similarity → softmax → cross-entropy; used for visual and text/video encoders — [ml-design](17-ml-design.md)
- Cross-entropy (CE) — offline CTR metric (model CE normalized against the background-CTR baseline's CE); also the per-class loss in detection and contrastive softmax loss — [ml-design](17-ml-design.md)
- DCN — Deep & Cross Network; learns feature crosses automatically instead of manual crossing; pick after the LR baseline — [ml-design](17-ml-design.md)
- DeepFM — FM (low-order interactions) + DNN (high-order) sharing embeddings; CTR model-zoo winner but slows continual learning — [ml-design](17-ml-design.md)
- Discretization — bucketing continuous features (e.g., post-age buckets) — [ml-design](17-ml-design.md)
- DistilmBERT — distilled multilingual BERT; text encoder for per-policy harmful-content classifiers — [ml-design](17-ml-design.md)
- Diversity — recommendation quality beyond accuracy; enforced by multiple candidate generators and re-ranking; an explicit offline metric in video rec — [ml-design](17-ml-design.md)
- Early fusion — concatenates modalities early so the model captures cross-modal interactions (memes: text and image benign separately, harmful combined) — [ml-design](17-ml-design.md)
- Edge prediction — frames link recommendation as predicting edges on the social graph rather than pointwise ⟨user, user⟩ ranking, using one-hop neighborhood context — [ml-design](17-ml-design.md)
- Embeddings — learned dense vectors where semantic similarity = geometric proximity; the shared currency of retrieval, ranking, and graph models — [ml-design](17-ml-design.md)
- ETL — extract-transform-load data-engineering vocabulary expected in the data-preparation step — [ml-design](17-ml-design.md)
- Faiss — library shipping ANN indexes (with ScaNN) for billion-scale retrieval — [ml-design](17-ml-design.md)
- Feature crossing — combining features to expose interactions; manual crossing explodes sparsity, so DCN/DeepFM learn crosses automatically — [ml-design](17-ml-design.md)
- Feature hashing — maps unseen/viral hashtags into a fixed feature space without retraining vocabularies — [ml-design](17-ml-design.md)
- Feature store — offline store of batch-computed static features fetched at serving time; dynamic features computed at query time — [ml-design](17-ml-design.md)
- Feedback-loop bias — over-recommended frequent users become over-represented in training data, compounding their representation — [ml-design](17-ml-design.md)
- FM — factorization machine: LR plus learned pairwise interactions via embeddings; DeepFM's low-order half — [ml-design](17-ml-design.md)
- Focal loss — loss for extreme class imbalance that down-weights easy negatives (event attendance) — [ml-design](17-ml-design.md)
- Friends-of-friends (FoF) — candidate narrowing from 1B users to ~1M (1000²); a Meta study found 92% of new friendships form within FoF — [ml-design](17-ml-design.md)
- Fusing layer — serving component merging multiple retrievers' results; weighted-sum re-rank chosen over a trained fusion model (extra training, latency) — [ml-design](17-ml-design.md)
- GBDT — gradient-boosted trees; strong tabular baseline but not fine-tunable, so wrong for continual learning at scale — [ml-design](17-ml-design.md)
- GNN — graph neural network producing node embeddings; dot product = edge probability (PYMK) — [ml-design](17-ml-design.md)
- Hard negative mining — sourcing realistic negatives because random ones are trivially separable: user-reported missed faces (blurring), same-region listings (similar listings) — [ml-design](17-ml-design.md)
- Harmful impressions — what users actually see, distinguished from prevalence (what exists on platform); tracked with valid appeals + proactive detection rate — [ml-design](17-ml-design.md)
- Hide rate — online ad metric: how often users hide ads; guards against irritating targeting — [ml-design](17-ml-design.md)
- High-cardinality sparse features — millions of IDs, mostly zeros; the core CTR-modeling challenge driving embeddings, DCN, DeepFM — [ml-design](17-ml-design.md)
- Hybrid recommendation — blends content-based (no cold start, poor discovery) and CF (discovers, cold-start pain); YouTube chose a CF-heavy hybrid — [ml-design](17-ml-design.md)
- Implicit feedback — abundant but noisy behavioral signals (watches) vs scarce explicit ratings; the standard recommendation choice — [ml-design](17-ml-design.md)
- Impression-based labeling — ad labels from logs: impression visible for a duration without click = negative; click within t seconds (tuned hyperparameter) = positive — [ml-design](17-ml-design.md)
- Integer encoding — encoding for ordinal categories preserving order; one-hot for nominal, embeddings for high cardinality — [ml-design](17-ml-design.md)
- Inverted index — term→documents map (Elasticsearch) giving zero-ML-cost text retrieval; fused with ANN results in video search — [ml-design](17-ml-design.md)
- IOU — intersection over union; a detection counts only above an IOU threshold — [ml-design](17-ml-design.md)
- Late fusion — separate per-modality models whose outputs merge; misses cross-modal interactions, so rejected for harmful memes — [ml-design](17-ml-design.md)
- mAP — mean average precision; averages AP over classes (detection) and serves as the ranking metric when relevance is binary (events, PYMK) — [ml-design](17-ml-design.md)
- Metric elimination chain — written reasoning discarding metric candidates for stated reasons (MRR vs recall@k vs precision@k vs nDCG); reproducing it signals senior judgment — [ml-design](17-ml-design.md)
- ML objective translation — the load-bearing move of turning a business goal into a trainable target: "increase engagement" → "maximize watch time" — [ml-design](17-ml-design.md)
- MRR — mean reciprocal rank; chosen when there is exactly one relevant item and rank position matters (video search); fails with many hits — [ml-design](17-ml-design.md)
- MSE — box-regression loss in detection, balanced with classification cross-entropy by λ — [ml-design](17-ml-design.md)
- Multi-task neural network — shared layers with one head per task (per policy, per reaction); beats N independent DNNs on cost and rare-task data starvation — [ml-design](17-ml-design.md)
- NCE — normalized cross-entropy: CE divided by the background-CTR baseline's CE; NCE < 1 means beating the naive baseline — [ml-design](17-ml-design.md)
- nDCG — normalized discounted cumulative gain; handles continuous relevance scores and millions of relevant items — [ml-design](17-ml-design.md)
- Negative sampling — word2vec-style training pairs: central vs context positive, central vs random negative; upgraded with same-region hard negatives — [ml-design](17-ml-design.md)
- One-hot encoding — sparse encoding for nominal categories; explodes with high cardinality, where embeddings take over — [ml-design](17-ml-design.md)
- Pointwise LTR — ranking as independent per-item classification ("will this user attend/click"); used for events and ad pCTR — [ml-design](17-ml-design.md)
- Positional bias — higher-ranked items collect more clicks regardless of quality, inflating winners in a feedback loop — [ml-design](17-ml-design.md)
- PR-AUC — precision-recall area under curve; per-policy metric for imbalanced harmful-content detection, with ROC-AUC — [ml-design](17-ml-design.md)
- Precision@k — fraction of top-k that are relevant; rank-blind, eliminated for visual search — [ml-design](17-ml-design.md)
- Precompute-and-cache — recurring pattern: index all embeddings offline, batch static features into a feature store, store whole recommendation lists; expensive work happens before the request — [ml-design](17-ml-design.md)
- Probability calibration — ad pCTRs feed downstream bidding; an uncalibrated model breaks the auction — [ml-design](17-ml-design.md)
- Quantization — compressing embeddings for memory in the indexing pipeline — [ml-design](17-ml-design.md)
- R-CNN family — two-stage detection: RPN proposes boxes, a classifier refines; slower but more accurate than one-stage — [ml-design](17-ml-design.md)
- Re-ranking — final serving stage for non-ML logic: privacy/duplicate filters, clickbait suppression, freshness, price/city rules — never baked into the model — [ml-design](17-ml-design.md)
- Recall@k — fraction of relevant items in top-k; drowns under millions of relevant items and degenerates to hit-rate with one relevant item — [ml-design](17-ml-design.md)
- Representation learning — learning embeddings so similar images sit close in N-dimensional space; the visual-search task framing — [ml-design](17-ml-design.md)
- ResNet — CNN image feature extractor for feed posts (with CLIP) — [ml-design](17-ml-design.md)
- Retrieval-then-rank serving — the skeleton shared by seven chapters: candidate generation → ranking (feature store) → re-ranking → top-K, fed by interaction logs for retraining — [ml-design](17-ml-design.md)
- ROC-AUC — threshold-independent ranking metric; per-reaction (feed) and per-policy (harmful content) for model quality, with mAP for ranking — [ml-design](17-ml-design.md)
- RPN — region proposal network; stage one of two-stage detection — [ml-design](17-ml-design.md)
- Scaling — min-max, z-score, or log transforms of numeric features; log for skew — [ml-design](17-ml-design.md)
- Self-supervision — free labels from data augmentation; chosen at billions scale over human judgment (accurate, expensive) and clicks (free, noisy, sparse) — [ml-design](17-ml-design.md)
- Session-based recommendation — recommends from recent interactions (a user browsing SF doesn't care about generic history); word2vec-lineage embeddings — [ml-design](17-ml-design.md)
- Softmax — turns similarity scores into a probability distribution for contrastive cross-entropy — [ml-design](17-ml-design.md)
- Two-stage detector — RPN + classifier architecture; chosen for accuracy at 1M training images where latency isn't a concern — [ml-design](17-ml-design.md)
- Two-tower model — separate user/item encoders meeting at a dot product; rich features and new-item support unlike matrix factorization — [ml-design](17-ml-design.md)
- ViT — vision Transformer; frame-level sampling + averaging chosen over expensive 3D-conv video models — [ml-design](17-ml-design.md)
- WALS — weighted alternating least squares; optimizes the MF loss over observed plus weighted unobserved pairs — [ml-design](17-ml-design.md)
- Weighted multi-reaction score — feed engagement objective: per-reaction probabilities × weights (click 1, like 5, comment 10, share 20, friend request 30, hide −20, block −50) — [ml-design](17-ml-design.md)
- word2vec — static embedding via sliding-window prediction with negative sampling; lineage of session/listing embeddings — [ml-design](17-ml-design.md)
- YOLO/SSD — one-stage detectors; faster, the choice when data or latency grows — [ml-design](17-ml-design.md)
